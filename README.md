# Marine Fouling Ecological Simulator

An interactive browser-based simulator for exploring marine fouling community succession in the San Francisco Bay context, using a Berkeley Marina submerged-panel baseline and adjustable hypothetical scenarios.

## Overview

The simulator lets users explore how three environmental variables may influence fouling-community composition:

- **Deployment duration:** 1–16 weeks
- **Sunlight exposure:** shaded dock or direct sun
- **Panel location:** Berkeley Marina or a hypothetical Bay-mouth/open-ocean setting

It compares a fixed baseline panel with a scenario panel and displays estimated surface coverage, a Shannon diversity index, organism growth trajectories, and community composition.

## Organisms and groups represented

- *Botryllus schlosseri*
- *Botrylloides violaceus*
- Solitary tunicates (including *Ciona* / *Styela*)
- Marine tube worms (Serpulidae)
- Macroalgae / film
- Uncolonized substrate

## Run locally

No build step or package installation is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

For a local development server, run:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy with GitHub Pages

1. Create a GitHub repository and upload the files in this project.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Scientific interpretation and limitations

**Important:** this is an exploratory visualization, not a validated ecological forecasting tool.

The application code defines a fixed 8-week, shaded Berkeley Marina baseline with the following surface-cover percentages:

| Group | Baseline value |
|---|---:|
| *Botryllus schlosseri* | 35% |
| *Botrylloides violaceus* | 25% |
| Solitary tunicates | 15% |
| Marine tube worms | 10% |
| Macroalgae / film | 0% |
| Uncolonized substrate | 15% |

The application labels these values as experimental baseline observations. The underlying experimental report or raw dataset is not included in this repository, so users should verify these numbers against the original report before treating them as empirical measurements or citing them.

Other combinations of duration, sunlight, and location are generated by equations and assumptions embedded in the JavaScript. They are **hypothetical model estimates**, not controlled field observations. The open-ocean/Bay-mouth condition is also a simulated comparison, not a second measured study site.

The model uses simplified logistic-style growth functions and a 100% surface-area constraint. Its outputs should be interpreted as scenario illustrations rather than calibrated predictions. The Shannon index is calculated from the modeled proportions of the represented biological groups.
